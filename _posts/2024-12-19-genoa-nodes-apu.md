The AMD Genoa partition for NEMO2 was delivered on December 4th. This partition consists of 106 compute nodes with 192 cores and 768 GB RAM each (total >20k cores). In addition, four APU nodes with 4x [AMD Instinct MI300A](https://www.amd.com/en/products/accelerators/instinct/mi300/mi300a.html) accelerator cards each and nine machines with 4x [NVIDIA L40S](https://www.nvidia.com/en-us/data-center/l40s/) each for machine learning and AI will be available in NEMO2.

As the acceptance of the storage has been delayed, we have not yet been able to launch NEMO2 this year. However, we have made the [Milan nodes in NEMO1](/news/2024/11/15/milan-nodes-nemo1/) available so that calculations are still possible in December and January. We will try to get the storage up and running in January and create instructions for the data transfer to the new system.

Happy holidays!
